# Estrutura de Dados II

Este repositório reúne estudos, implementações e exercícios desenvolvidos na disciplina de Estrutura de Dados II, com foco em estruturas de dados avançadas, análise de desempenho e manipulação eficiente de dados.

O objetivo deste projeto é consolidar conceitos fundamentais relacionados à organização, armazenamento e processamento de dados, explorando soluções com eficiência em tempo de execução e uso de memória.

## 📚 Conteúdos Abordados

Entre os principais tópicos estudados neste repositório estão:

- Árvores (Binárias, AVL, B-Trees)
- Tabelas Hash
- Filas de Prioridade
- Heaps
- Grafos e algoritmos de busca
- Ordenação e pesquisa
- Recursividade e análise de complexidade
- Manipulação de arquivos
- Algoritmos aplicados a problemas computacionais

## 🛠️ Tecnologias Utilizadas

- Linguagem: C++17 ou superior  
- Compilador: GCC / G++  
- Bibliotecas Standard:
  - `<iostream>`
  - `<fstream>`
  - `<vector>`
  - `<queue>`
  - `<stack>`
  - `<unordered_map>`
  - `<algorithm>`

## 🎯 Objetivos do Repositório

- Praticar conceitos de Estruturas de Dados Avançadas.
- Desenvolver soluções eficientes para problemas computacionais.
- Estudar desempenho de algoritmos.
- Aplicar conceitos teóricos em implementações práticas.
- Servir como material de apoio para estudos futuros.
